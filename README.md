CITADEL acts as an intelligent operating system for urban centers. It connects government departments with citizens through eight specialized modules. This tool manages everything from public document processing and traffic flow to civic support and expense tracking. It uses modern technology to streamline city operations and increase transparency for every resident.

## 📋 What This System Does

This platform organizes city functions into a single interface. It assists both administrators and members of the public with daily tasks.

* Document Intelligence: Scans and organizes city files for quick access.
* Traffic Enforcement: Uses cameras to monitor road safety.
* Anomaly Monitoring: Detects unusual events in public spaces.
* Civic RAG Assistant: Answers questions about local policies.
* Fake-News Detection: Verifies information shared on city platforms.
* Tickets: Tracks public service requests.
* Expenses: Monitors municipal spending logs.

The application requires no complex setup after installation. Once the program opens, you will reach the main dashboard. 

The dashboard displays all eight modules. Click any module icon to open its specific toolset. The first time you use the Civic RAG Assistant, the system might need to index your local data. Wait a few moments for this initial sync to finish.

If you encounter issues with traffic monitoring, ensure your camera permissions are active in your Windows settings. The system logs activity automatically, so you do not need to save your documents manually.

## 📁 Troubleshooting Common Issues

If the software fails to open:

* Check your internet connection. Some features require a link to the central server.
* Ensure your Windows version has the latest updates. Old versions of Windows may lack support for newer application features.
* Reinstall the program if an error message suggests corrupted files. Simply delete the existing folder and perform the download again from the link provided above.
